# 포춘옷장 — 이번 챌린지에서 할 일

> BF.D | 작성자: eunjihonglnl@gmail.com | 기간: 4주
> 주당 시간: 최소 3시간 | 사용할 도구·경험: Figma Make, Claude Design으로 MVP 제작 경험 있음 (비개발자·기획자)
> 상태: 작은 구현 시작 가능 (사주 규칙 리서치는 1주차에 진행) | 내 말로 설명: 확인됨

## 친구에게 설명하면
기획자가 디자이너 도움 없이도 완성도 있는 화면(hi-fi 프로토타입)을 만들 수 있게 돕는 나만의 방법을 정리하고, 그 방법으로 오늘의 사주 기반 행운 패션을 추천해주는 '포춘옷장' 서비스를 실제로 만들어서 테스트해볼 거예요.

## 지금 불편한 장면
기획자인 내가 Figma Make나 Claude Design으로 MVP를 만들 때, 디자인 위계나 시각적 완성도를 판단할 기준이 없어서 매번 레퍼런스 이미지를 주고 "이렇게 해줘"라고 요청하는 방식에 의존하고 있음. (확인된 본인 경험)

## 왜 풀어볼 만한가
- 실제 근거와 영향: 본인이 MVP를 만들 때마다 반복적으로 겪는 문제. 회사 신규 기획 업무에도 비슷하게 적용될 가능성이 있음 (회사 적용 효과는 이번 범위에서 확인 전).
- 지금 방법으로 부족한 점: 레퍼런스 이미지 제공 방식은 매번 새로 설명해야 하고, 재사용 가능한 기준이 없어 프로젝트마다 품질이 들쭉날쭉함.
- 아직 확인할 것: 정리한 Skill 문서만 보고 실제로 비슷한 품질의 화면을 다시 만들 수 있는지 (4주차에 직접 검증).

## 먼저 필요한 것
| 필요한 것 | 지금 상태와 근거 | 없거나 모르면 할 일·누가·언제 |
|---|---|---|
| 사주→행운색 계산 규칙 | 없음, 직접 만들 예정 (사용자 설명) | 1주차에 오행 기반 규칙 리서치 후 지인 3명 테스트로 "말이 되는지" 확인 |
| 쿠팡 파트너스 제휴 계정 | 있음 (사용자 확인) | 해당 없음 |
| 무신사 제휴 | 없음 | 이번 범위에서 제외, 쿠팡만 사용 |
| 테스트해줄 지인 | 있음, 지인 몇 명 (사용자 설명) | 2~3주차에 실제 생년월일시로 테스트 요청 |
| 회사 사주 로직/DB | 있음, 회사 자산 (사용자 설명) | 이번 개인 챌린지에서는 사용하지 않고 별도로 직접 제작 (IP 이슈 방지) |

## 이번에 만들 것
- 형태: (1) 포춘옷장 웹 MVP — 로그인 없는 간단한 웹페이지 (2) AI Skill 문서 — 디자이너 없이 hi-fi 화면 만드는 재사용 가능한 가이드
- 핵심 기능:
  1. 생년월일시 입력 → 오행 기반 오늘의 행운 색/스타일 계산
  2. 결과에 맞는 쿠팡 제품 추천 노출 (쿠팡 파트너스 링크)
  3. 제작 과정에서 쓴 판단 기준(레퍼런스 비교 + AI 자체 점검 체크리스트)을 AI Skill 문서로 정리
- 이번에 미룰 것: 무신사 연동, 회원가입/결과 저장, 자동 알림, Skill을 다른 프로젝트에서 재검증하는 것(다음 챌린지)
- 보여줄 흐름: 본인 실제 생년월일시(실제 자료) 입력 → 행운 색/스타일 결과 표시 → 쿠팡 추천 제품 노출·링크 클릭

## 잘됐는지 확인하기
- 확인 방법: 지인 3~5명이 실제 생년월일시로 써보고 "그럴듯하다 / 화면이 자연스럽다" 반응 확인 + 본인이 레퍼런스 3개와 나란히 비교 + AI에게 화면 스크린샷 자체 점검 요청. Skill 문서는 4주차에 그 문서만 보고 새 화면 하나를 만들어봐서 "따라 만들 수 있는지"로 확인.
- 가장 먼저 확인할 것: 사주→행운색 규칙을 본인이 신뢰할 만하게 만들 수 있는지. 1주차 리서치 후 지인 3명 테스트에서 "말이 된다" 반응이면 계속 진행, 아니면 규칙을 더 단순화하거나 참고 자료를 바꾼다.
- 이 확인만으로는 알 수 없는 것: 지인이 아닌 낯선 사람도 이 화면·제품을 좋다고 느끼는지, Skill 문서가 본인 외 다른 사람에게도 통하는지는 이번 범위에서 확인되지 않음.

## 언제 무엇을 할까
| 주차 | 보여줄 결과물 |
|---|---|
| 1주차 | 사주→행운색 규칙 리서치 + 지인 3명 테스트로 검증, 포춘옷장 레퍼런스 수집·화면 설계 시작 |
| 2주차 | 포춘옷장 핵심 화면 구현(입력→결과→쿠팡 추천), 레퍼런스 비교+AI 자체 점검으로 다듬기 |
| 3주차 | 지인 3~5명 실사용 테스트 및 반영, 쓴 판단 기준을 AI Skill 문서 초안으로 정리 |
| 4주차 | Skill 문서로 새 화면 하나 만들어 검증 + 포춘옷장 다듬기·배포(Vercel) |
